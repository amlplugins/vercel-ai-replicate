# @amlplugins/vercel-ai-replicate

Native `@ai-sdk/replicate` SDK re-exported under the `@amlplugins` namespace.

> Vercel AI SDK Replicate provider — image-generation adapter for FLUX, SDXL, SD3 via Replicate models.

## Install

```bash
npm install @amlplugins/vercel-ai-replicate
```

## Use

```ts
import { /* named exports from @ai-sdk/replicate */ } from "@amlplugins/vercel-ai-replicate";
// or
import sdk from "@amlplugins/vercel-ai-replicate";
```

This package additionally re-exports `ai` under the `secondary` namespace.

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
